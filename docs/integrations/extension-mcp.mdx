[extension.dev](https://extension.dev), the platform that sponsors Extension.js, ships `@extension.dev/mcp`, a Model Context Protocol server, and `@extension.dev/skill`, an agent skill. Both are extension.dev products with their own repositories and documentation. They work with any Extension.js project. The server wraps the `extension` CLI and the local control channel that `extension dev` opens. An agent can then build, run, inspect and reload your extension in a real browser, with the same gates that the CLI enforces.

Extension.js itself is the framework and the CLI. Nothing in it depends on the agent tooling, and every operation that the server exposes is also a CLI verb. See [Debugging](/docs/debugging).

## Install

```bash
claude mcp add extension-dev npx @extension.dev/mcp
```

Other clients and the plugin install are on [docs.extension.dev/tools/mcp](https://docs.extension.dev/tools/mcp).
