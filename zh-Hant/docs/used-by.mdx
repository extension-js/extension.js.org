以下是依賴 Extension.js 的公開專案，透過它們的 `package.json` 找到。Star 數量屬於儲存庫，而不是擴充功能的使用者數。要加入你的專案，請提交一個向此表格新增一列的 pull request。

| 專案 | 簡介 | 儲存庫 |
| --- | --- | --- |
| Better Lyrics | YouTube Music 的時間同步歌詞，已發布到 Chrome Web Store 和 Firefox Add-ons | [better-lyrics/better-lyrics](https://github.com/better-lyrics/better-lyrics) |
| Apollo Dreamview 除錯擴充功能 | 百度 Apollo 自動駕駛平台內建的瀏覽器除錯工具 | [ApolloAuto/apollo](https://github.com/ApolloAuto/apollo/tree/master/modules/dreamview_plus/frontend/packages/dreamview-debug-extension) |
| dmMiniPlayer 元素選擇器 | dmMiniPlayer 子母畫面播放器的元素選擇擴充功能 | [apades/dmMiniPlayer](https://github.com/apades/dmMiniPlayer/tree/main/packages/element-picker-ext) |
| Opal Connect | 開源媒體播放器 Opal 的瀏覽器伴侶擴充功能 | [debpalash/Opal](https://github.com/debpalash/Opal/tree/main/extension) |

## 加入你的專案

向 [extension-js/docs](https://github.com/extension-js/docs) 提交一個 pull request，新增一列：專案名稱、一句話簡介和儲存庫連結。專案必須是公開的，且其 `package.json` 必須將 `extension` 列為相依套件。
