使用 `uninstall` 從 Extension.js 快取中移除受管理的瀏覽器執行階段。

<Warning>
  `uninstall` 移除的是 Extension.js 下載到其受管理快取中的瀏覽器執行階段。它從不移除你的系統瀏覽器，也從不移除安裝在瀏覽器裡的擴充功能。要移除一個開發中的擴充功能，停止 `dev` 工作階段即可。該擴充功能載入的是受管理的瀏覽器設定檔，而不是你自己的瀏覽器設定檔。
</Warning>

## 何時使用 `uninstall`

- 你想釋出受管理瀏覽器佔用的磁碟空間,因為已不再需要。
- 你想重設某個受管理瀏覽器的安裝,讓下次 `install` 時強制重新下載。
- 你正在清理持續整合(CI)的快取,或切換瀏覽器目標。

單一瀏覽器使用位置引數形式:

<CodeGroup>






使用 `--all` 移除所有受管理的瀏覽器目標。

## 引數與旗標

| 旗標 / 引數           | 用途                                                                | 預設值 |
| --------------------- | ------------------------------------------------------------------- | ------ |
| `[browser-name]`      | 移除單一受管理瀏覽器,例如 `chrome`、`chromium`、`edge` 或 `firefox` | 未設   |
| `--browser <browser>` | 上述瀏覽器引數的明確旗標形式                                        | 未設   |
| `--all`               | 移除 Extension.js 快取中所有受管理的瀏覽器執行階段                  | 停用   |
| `--where`             | 印出解析後的快取根目錄,或特定瀏覽器的受管理路徑                     | 停用   |
| `--output <pretty\|json>` | 結果格式。`json` 會在 stdout 上印出一個 schema-1 信封              | `pretty` |

`--all` 移除的是與 `install --browser all` 建立的相同受管理集合:`chrome`、`chromium`、`edge` 與 `firefox`。

## 用 `--output json` 輸出機器可讀結果

`--output json` 會在 stdout 上印出一個 schema-1 信封:

- 移除成功會印出 `status: "uninstalled"` 幀,並在 `value` 中指出目標。
- `--where` 會印出 `status: "located"` 幀,解析後的路徑放在 `value.paths`。
- 移除失敗會印出 `ok: false` 與 `error.code: "E_BROWSER_UNINSTALL"`,接著行程以 `1` 結束。

從 4.1.41 之後的版本起，`value` 包含 `browsers`、`all`，以及一個 `results` 陣列，每個目標一項。每一項有 `browser`、`removed`、`path`（檢查過的受管資料夾）與 `outcome`：

| `outcome` | 含義 |
| --------- | ---- |
| `removed` | 受管瀏覽器已移除。 |
| `absent`  | 快取中沒有這個目標的受管瀏覽器。沒有瀏覽器的資料夾會被靜默清除。 |
| `system`  | 僅限 Edge。沒有找到受管的 Edge，位於 `systemPath` 的系統 Edge 保持原樣。 |
| `failed`  | 資料夾仍然存在。`reason` 說明原因。 |

`uninstall` 會先嘗試每個目標，然後才失敗。失敗的執行仍會印出 `value.results`，所以腳本可以看到哪些目標已被移除。沒有移除任何目標時，狀態為 `noop`，幀中帶有一則 `W_UNINSTALL_NOOP` 警告。

## 範例

### 移除受管理的 Chrome for Testing

```bash
extension uninstall chrome
```

### 移除所有受管理的瀏覽器

```bash
extension uninstall --all
```

### 顯示 Firefox 的受管理移除路徑

```bash
extension uninstall firefox --where
```

## 最佳實務

- **在 CI 收尾使用 `--all`**,在測試後清理受管理的瀏覽器。
- **先使用 `--where`**,在大量移除前確認會被清掉的內容。

## 行為說明

- 如果你設定了 `EXT_BROWSERS_CACHE_DIR`,uninstall 會使用該自訂快取根目錄。
