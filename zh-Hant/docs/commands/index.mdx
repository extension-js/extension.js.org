依照擴充功能開發目前所處的階段,從首次建立到正式版驗證,選擇合適的指令。

## 指令選擇

| 目標                       | 指令        | 範例                                                            |
| -------------------------- | ----------- | --------------------------------------------------------------- |
| 建立新專案                 | `create`    | `npx extension@latest create my-extension --template=newtab-react` |
| 以監看模式開發             | `dev`       | `extension dev --browser=firefox`                               |
| 建置正式版產物             | `build`     | `extension build --browser=chrome,firefox --zip`                |
| 建置並啟動正式版輸出       | `start`     | `extension start --browser=edge`                                |
| 只啟動既有建置輸出         | `preview`   | `extension preview --browser=chrome`                            |
| 取得專案的可分享 URL | `publish` | `extension publish --ttl=4` |
| 安裝受管理的瀏覽器執行階段 | `install`   | `extension install chrome`                                      |
| 移除受管理的瀏覽器執行階段 | `uninstall` | `extension uninstall chrome`                                    |
| 診斷執行中的 dev 工作階段  | `doctor`    | `extension doctor --browser=chromium`                           |
| 讀取或串流工作階段記錄 | `logs` | `extension logs --follow --context background,content` |
| 列出分頁或檢視 DOM | `inspect` | `extension inspect --tab 412 --with-console` |
| 在執行中的內容環境執行程式碼 | `eval` | `extension eval "location.href" --context page` |
| 讀寫擴充功能 storage | `storage` | `extension storage get --key settings` |
| 依需求重新載入某個內容環境 | `reload` | `extension reload --context background` |
| 開啟某個介面或重播一個動作 | `open` | `extension open popup` |
| 供腳本與 agent 使用的握手 | `capabilities` | `extension capabilities` |

直接執行不帶指令的 `extension` 會印出完整說明,並以結束碼 `0` 離開。

## 典型開發者流程

1. `create` 建立專案。
2. `dev` 進行迭代開發與重新載入循環。
3. `build` 產生正式版產物。
4. `preview` 或 `start` 做接近正式版的驗證。
5. 需要明確管理 Extension.js 瀏覽器執行階段時,使用 `install` 或 `uninstall`。
6. 使用 `logs`、`inspect`、`eval`、`storage`、`reload` 與 `open` 觀察並操作執行中的工作階段。
7. dev 工作階段或與它溝通的自動化 verb 不再回應時,使用 `doctor`。
8. 由腳本或 agent(而不是人)驅動 CLI 時,先使用 `capabilities`。
