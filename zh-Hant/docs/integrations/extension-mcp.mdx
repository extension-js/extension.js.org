贊助 Extension.js 的平台 [extension.dev](https://extension.dev) 提供 `@extension.dev/mcp`（一個 Model Context Protocol 伺服器）和 `@extension.dev/skill`（一個 agent skill）。兩者都是 extension.dev 的產品，擁有各自的儲存庫和文件。它們可以搭配任何 Extension.js 專案使用。該伺服器封裝了 `extension` CLI 以及 `extension dev` 開啟的本機控制通道。agent 因此可以在真實瀏覽器中建置、執行、檢視和重新載入你的擴充功能，並受到與 CLI 相同的限制。

Extension.js 本身是框架和 CLI。它不依賴任何 agent 工具，伺服器提供的每個操作也都是 CLI 動詞。請見[除錯](/zh-Hant/docs/debugging)。

## 安裝

```bash
claude mcp add extension-dev npx @extension.dev/mcp
```

其他用戶端和外掛安裝方式請見 [docs.extension.dev/tools/mcp](https://docs.extension.dev/tools/mcp)。

## 文件位置

- [MCP 伺服器](https://docs.extension.dev/tools/mcp)：安裝、工具清單、session 限制和登入。
- [Agent skill](https://docs.extension.dev/tools/skill)：skill 教給 agent 的內容以及安裝方式。
- [與 Chrome DevTools MCP 並用](https://docs.extension.dev/tools/chrome-devtools-mcp)：該選哪個伺服器，以及如何同時安裝兩者。
