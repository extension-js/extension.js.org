跨足框架、文件網站與周邊開發者體驗的貢獻者,共同形塑了 Extension.js 與 `extension.js.org` 這兩項開源專案。

你可以用多種方式貢獻:編譯器與執行期工作、文件、範例、設計與意見回饋。本頁致敬框架與文件網站的貢獻者。

## 支持者

以每月贊助資助 Extension.js 的個人。慷慨支持者優先列出,並附上自選連結。完整列表見 [BACKERS.md](https://github.com/extension-js/extension.js/blob/main/BACKERS.md)。

## 成為贊助商

每個等級都包含其下所有等級的權益。持續贊助取得展示位,一次性捐贈會在 BACKERS.md 中致謝。贊助不包含活動推廣或宣傳活動。

| 等級 | 每月 | 權益 |
| --- | --- | --- |
| 支持者 | $5 | 名字出現在 BACKERS.md 與本頁 |
| 慷慨支持者 | $25 | 名字與連結,列於其他支持者之上 |
| 青銅贊助商 | $50 | Logo 與連結出現在本頁與 BACKERS.md |
| 白銀贊助商 | $200 | Logo 與連結出現在 extension.js.org 首頁以及 GitHub 與 npm 的 README |
| 黃金贊助商 | $500 | 更大的首頁展示位、issue 優先處理、當你發布擴充功能開發者應該知道的內容時由 @extensionjs 發文 |
| 白金贊助商 | $1,000 | 置頂位置與標示、在 extension-js/examples 中共建一個範例、每季一次路線圖通話、每季一則由你撰寫文案的貼文 |
| 合作夥伴 | 協議 | 唯一的「In partnership with」展示位以及共同商定的整合工作 |

前往 [github.com/sponsors/cezaraugusto](https://github.com/sponsors/cezaraugusto) 贊助。贊助後請寄送淺色與深色兩版 SVG Logo 以及你希望使用的連結,歡迎信會說明寄送方式。
