## 以本地為設計前提

Extension.js 在你自己的機器上執行：用 CLI 開發、執行並建置擴充功能。它刻意止於打包。
當打包好的建置準備好上架商店時，下一步是
[extension.dev](https://extension.dev?utm_source=extension-js-org&utm_medium=sponsor&utm_campaign=docs-seam)——
贊助 Extension.js 的那個平台。

## 事前準備

<Warning>
  Extension.js 需要 Node.js 22.12 或更新版本。CLI 會在任何其他程式碼執行之前先檢查執行環境，
  較舊的 Node.js 會以結束碼 1 結束，並印出一則升級訊息。
</Warning>

開始之前，請先用 `node --version` 檢查你的版本。

## 第一次成功的成果

<Steps>
  <Step title="建立或執行一個擴充功能專案">
    使用 `extension create` 或選一個範本作為起點。
  </Step>
  <Step title="啟動 dev 並載入擴充功能">
    執行 `extension dev`，並在目標瀏覽器中載入建置輸出。
  </Step>
  <Step title="驗證更新行為">做一次變更，並確認擴充功能會自動重新載入。</Step>
  <Step title="建置正式輸出">至少對一種瀏覽器執行 `extension build`。</Step>
</Steps>

<Note>
  **第一次執行。** `extension dev` 預設以 `chromium` 為目標，在一個版本固定的 Chrome for Testing
  和隔離設定檔中執行你的擴充功能，絕不碰你平常瀏覽用的瀏覽器。當本機還沒有這個瀏覽器時，
  第一次執行會詢問是否下載一次，下載完成後直接繼續進入開發工作階段。

  回答 `n` 就不會下載任何東西。你可以隨時執行 `npx extension install chromium`，
  用 `--browser=edge` 或 `--browser=brave` 使用已安裝的瀏覽器，用 `--chromium-binary <path>`
  固定任意執行檔，或用 `--no-browser` 只啟動開發伺服器。非互動式 shell，包括 CI，不會被詢問：
  它會印出安裝指令並停止。請見
  [為什麼 Extension.js 會下載瀏覽器](/zh-Hant/docs/commands/install#why-extensionjs-downloads-a-browser)
  與 [略過受管下載](/zh-Hant/docs/commands/install#skip-the-managed-download)。
</Note>
