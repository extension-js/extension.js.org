## 成为赞助商

每个级别都包含其下所有级别的权益。持续赞助获得展示位，一次性捐赠会在 BACKERS.md 中致谢。赞助不包含活动推广或宣传活动。

| 级别 | 每月 | 权益 |
| --- | --- | --- |
| 支持者 | $5 | 名字出现在 BACKERS.md 和本页 |
| 慷慨支持者 | $25 | 名字和链接，列于其他支持者之上 |
| 青铜赞助商 | $50 | Logo 和链接出现在本页和 BACKERS.md |
| 白银赞助商 | $200 | Logo 和链接出现在 extension.js.org 首页以及 GitHub 和 npm 的 README |
| 黄金赞助商 | $500 | 更大的首页展示位、issue 优先处理、当你发布扩展开发者应该了解的内容时由 @extensionjs 发布推文 |
| 白金赞助商 | $1,000 | 置顶位置和标识、在 extension-js/examples 中共建一个示例、每季度一次路线图通话、每季度一条由你撰写文案的推文 |
| 合作伙伴 | 协商 | 唯一的「In partnership with」展示位以及共同商定的集成工作 |

前往 [github.com/sponsors/cezaraugusto](https://github.com/sponsors/cezaraugusto) 赞助。赞助后请发送浅色和深色两版 SVG Logo 以及你希望使用的链接，欢迎邮件会说明发送方式。
