## 本地优先的设计

Extension.js 运行在你自己的机器上：用 CLI 开发、运行并构建扩展。它有意止步于打包。
当打包好的构建产物准备好上架商店时，下一步是
[extension.dev](https://extension.dev?utm_source=extension-js-org&utm_medium=sponsor&utm_campaign=docs-seam)——
赞助 Extension.js 的那个平台。

- **想用现有示例快速尝试：** [立即上手](/docs/getting-started/immediately)

## 前置条件

<Warning>
  Extension.js 需要 Node.js 22.12 或更新版本。CLI 会在任何其他代码运行之前检查运行时，
  更旧的 Node.js 会以退出码 1 结束，并给出一条升级提示。
</Warning>

开始之前，请先用 `node --version` 检查你的版本。

## 第一次成功的目标

<Steps>
  <Step title="搭建或运行一个扩展项目">
    使用 `extension create`，或选择一个模板作为起点。
  </Step>
  <Step title="启动 dev 并加载扩展">
    运行 `extension dev`，把构建产物加载到目标浏览器中。
  </Step>
  <Step title="验证更新行为">修改一处，确认扩展能够重新加载。</Step>
  <Step title="构建生产产物">至少为一个浏览器运行 `extension build`。</Step>
</Steps>
