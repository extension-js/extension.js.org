以下是依赖 Extension.js 的公开项目，通过它们的 `package.json` 找到。Star 数量属于仓库，而不是扩展的用户数。要添加你的项目，请提交一个向此表格新增一行的 pull request。

| 项目 | 简介 | 仓库 |
| --- | --- | --- |
| Better Lyrics | YouTube Music 的时间同步歌词，已发布到 Chrome Web Store 和 Firefox Add-ons | [better-lyrics/better-lyrics](https://github.com/better-lyrics/better-lyrics) |
| Apollo Dreamview 调试扩展 | 百度 Apollo 自动驾驶平台内置的浏览器调试工具 | [ApolloAuto/apollo](https://github.com/ApolloAuto/apollo/tree/master/modules/dreamview_plus/frontend/packages/dreamview-debug-extension) |
| dmMiniPlayer 元素选择器 | dmMiniPlayer 画中画播放器的元素选择扩展 | [apades/dmMiniPlayer](https://github.com/apades/dmMiniPlayer/tree/main/packages/element-picker-ext) |
| Opal Connect | 开源媒体播放器 Opal 的浏览器伴侣扩展 | [debpalash/Opal](https://github.com/debpalash/Opal/tree/main/extension) |

## 添加你的项目

向 [extension-js/docs](https://github.com/extension-js/docs) 提交一个 pull request，新增一行：项目名称、一句话简介和仓库链接。项目必须是公开的，且其 `package.json` 必须将 `extension` 列为依赖。
