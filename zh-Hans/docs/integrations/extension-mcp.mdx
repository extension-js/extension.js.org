赞助 Extension.js 的平台 [extension.dev](https://extension.dev) 提供 `@extension.dev/mcp`（一个 Model Context Protocol 服务器）和 `@extension.dev/skill`（一个 agent skill）。两者都是 extension.dev 的产品，拥有各自的仓库和文档。它们可以配合任何 Extension.js 项目使用。该服务器封装了 `extension` CLI 以及 `extension dev` 打开的本地控制通道。agent 因此可以在真实浏览器中构建、运行、检查和重载你的扩展，并受到与 CLI 相同的门控约束。

Extension.js 本身是框架和 CLI。它不依赖任何 agent 工具，服务器暴露的每个操作也都是 CLI 子命令。参见[调试](/zh-Hans/docs/debugging)。

## 安装

```bash
claude mcp add extension-dev npx @extension.dev/mcp
```

其他客户端和插件安装方式见 [docs.extension.dev/tools/mcp](https://docs.extension.dev/tools/mcp)。
